Перші кроки після завантаження

  1. Розпакуйте весь ZIP зі збереженням структури тек. Переглядайте PDF, шпаргалку й демо без встановлення програм.
  2. Для власної практики потрібні Python 3.10+, Git, SQLcl, Claude Code та збережене навчальне зʼєднання SQLcl train із Сесії 1. У Windows для Claude Code також потрібен Git Bash.
  3. Відкрийте термінал у теці з START-HERE.html й виконайте наведені команди.
python training/session-2/check-environment.py
python training/session-2/check-environment.py --database
python training/session-2/setup-workspace.py
cd training/session-2/workspace

Очікуйте PREFLIGHT_PASS, а після підготовки теки — WORKSPACE_READY. Якщо Python запускається як python3, використовуйте цю назву. Наявну робочу теку скрипт не перезаписує.

Далі відкрийте підготовку й пояснення в уроці або команди початку лабораторії.

Що працює без мережі, а що потребує доступу

PDF, шпаргалка, повний текстовий урок, записи та локальна підготовка теки працюють із розпакованого архіву. Для підготовки теки потрібні встановлені Python і Git. Для запуску Claude потрібні мережа й власний вхід. Для SQL потрібні SQLcl і ваш навчальний доступ до Oracle. Wallet, пароль та обліковий запис у публічний архів не входять.
