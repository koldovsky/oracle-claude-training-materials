8 · Домашнє завдання №2

Один власний skill або hook

Оберіть одну повторювану задачу й зробіть власний skill або hook. Працюйте із синтетичними прикладами.

  • Позитивний випадок: коректний код або дозволена дія проходять; skill не вигадує порушень.
  • Негативний випадок: навмисне порушення знайдено з доказом або заборонену дію заблоковано.
  • Граничний випадок: для skill — бракує потрібного контексту; для hook — неповний або неправильний вхід. Заздалегідь визначте очікувану поведінку.

Докази: README з кроками запуску, файл розширення, очікування до запуску, фактичні відповіді або коди завершення, відомі межі. Негативний hook-тест подає текст як тестові дані; небезпечну команду не виконуємо.

Рубрика — 5 × 2 бали: конкретна задача; відтворювані інструкції; позитивний і негативний приклади; контекст і межі; перевірюваний результат. Готовність — від 8/10, обидва основні приклади обов'язкові.
