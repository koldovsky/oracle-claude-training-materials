# Публічні матеріали Сесії 2

Вхід для учасника: `session-2.html`. Звідти доступні слайди, самостійний урок,
шпаргалка, відеоурок і файли для завантаження. Сторінка `session-2-slides.html`
показує 26 сторінок чинного PDF як зображення та має посилання на оригінальний PDF.
Файли `tools/session-2*.html` призначені для локального архіву. Публічні варіанти
мають інші посилання на документи й завантаження.

## Порядок підготовки

Команди виконуються з кореня навчального репозиторію. Спочатку перебудуйте
самостійний урок і відеоурок їхніми генераторами. Після цього:

```bash
python training/session-2/build-cheatsheet.py --public-dir .public-repo/docs
python training/session-2/build-student-hub.py
python training/session-2/package-materials.py
python training/session-2/build-student-hub.py --public-dir .public-repo/docs --validate-links
```

Перед першим створенням зображень слайдів або після зміни PDF використайте:

```bash
python training/session-2/build-student-hub.py --render-slides
```

Для цього кроку потрібен Poppler (`pdftoppm` у `PATH`). Генератор звіряє SHA-256
PDF і кожного зображення. Без зміни PDF повторна растеризація не потрібна.

`package-materials.py` включає лише дозволені файли, перевіряє початкове тіло
пакета, цілісність архіву та підготовку чистої Git-теки після розпакування.
Архів починається з `START-HERE.html` і містить усі навчальні файли, PDF,
переглядач слайдів, шпаргалку та самостійний урок. Відео завантажується окремо.
Персональні доступи, wallet, сирі журнали й тренерські файли до архіву не входять.

Остання команда копіює точні байти ZIP і PDF у `docs/downloads/`, створює
`session-2-downloads.json` із розмірами та SHA-256, копіює сторінки слайдів,
додає посилання на Сесію 2 до наявної головної сторінки Сесії 1 та перевіряє
локальні посилання п'яти навчальних HTML-сторінок. Команду слід повторювати
після перебудови головної Slidev-сторінки, щоб відновити посилання на Сесію 2.

Генератори готують локальні файли. Коміти та публікацію виконують окремо після
перевірки всіх матеріалів.
