# Claude Code + Oracle — навчальне середовище

Готове ізольоване середовище для навчання роботі з Claude Code на Oracle.
Відкривається в **GitHub Codespaces** — на комп'ютері нічого встановлювати не треба.

Усередині контейнера вже є: Claude Code, SQLcl, Java 21, підключення до навчальної
бази через MCP. Дані виключно синтетичні (офіційні sample-схеми Oracle).

---

## Швидкий старт

1. **Спершу додайте свої секрети** — див. розділ нижче. Без них Codespace підніметься, але без доступу до бази.
2. Натисніть **Code → Codespaces → Create codespace on main**
3. Дочекайтесь збірки контейнера (перший раз ~3-5 хв)
4. У терміналі виконайте `claude` і увійдіть у свій акаунт — див. застереження нижче
5. Спробуйте: *«покажи список таблиць у схемі HR»*
6. Claude попросить дозволу на MCP-сервер `sqlcl` — підтвердіть

Claude звернеться до бази через MCP-сервер SQLcl і відповість реальними даними.

> ### ⚠️ Вхід у Claude Code в Codespaces
>
> Браузер повертає код автентифікації на `http://localhost:<порт>`, а цей порт до контейнера не прокидається — сторінка не відкриється. **Це нормально.**
>
> З адреси, на якій браузер спіткнувся, візьміть параметри `code` і `state` та вставте в термінал на запит `Paste code here if prompted >`, з'єднавши їх решіткою:
>
> ```
> <code>#<state>
> ```
>
> Код живе кілька хвилин. Якщо не встигли — `/login` заново.

## Секрети

Секрети поділені на два рівні — і це принципово.

### Спільні (рівень репозиторію) — налаштовує тренер, один раз

| Секрет | Значення |
|---|---|
| `ADB_WALLET_B64` | wallet у base64: `base64 -w0 wallet.zip` |
| `ADB_SERVICE` | напр. `acordtrain_low`. Сервіс `_low` обмежує паралелізм одного запиту й дає більше одночасних сесій |

Wallet прив'язаний до бази, а не до користувача, тож він однаковий у всіх.
Отримується з консолі OCI (**Autonomous Database → Database connection → Download wallet**)
або скриптом [`setup/03-download-wallet.sh`](setup/03-download-wallet.sh).

### Особисті (рівень користувача) — кожен налаштовує собі

**Ваші GitHub Settings → Codespaces → Secrets → New secret**, і в полі
**Repository access** оберіть цей репозиторій.

| Секрет | Значення |
|---|---|
| `ADB_USER` | ваш логін, напр. `TRAINEE1` — видає тренер |
| `ADB_PASSWORD` | ваш пароль — видає тренер |

> **Чому саме так.** Якби логін і пароль лежали на рівні репозиторію, усі
> учасники підключалися б під одним обліковим записом — в одну спільну схему.
> Ізоляція, заради якої все будувалося, зникла б. Тому на рівні репозиторію
> навмисно немає нічого персонального.

Після додавання секретів перестворіть Codespace, щоб `post-create.sh` їх підхопив.

## Структура

```
.devcontainer/
  Dockerfile          Java 21 + SQLcl
  devcontainer.json   Claude Code, Node, том для ~/.claude
  post-create.sh      Розпаковує wallet, зберігає з'єднання, перевіряє його
.mcp.json             MCP-сервер SQLcl — однаковий для всіх учасників
setup/                Скрипти розгортання БД (виконуються тренером один раз)
```

`.mcp.json` лежить у репозиторії навмисно: завдяки цьому всі учасники
отримують ідентичне підключення автоматично, без ручного налаштування.

## Безпека

- Жодних реальних чи конфіденційних даних — тільки офіційні sample-схеми Oracle
- Wallet і паролі передаються через Codespaces secrets, у git не потрапляють
- `.gitignore` окремо перекриває wallet-файли на випадок помилки
- Телеметрія Claude Code вимкнена (`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`)

Wallet — це облікові дані. Не пересилайте його у чатах і не комітьте.
