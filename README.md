# Claude Code + Oracle — навчальне середовище

Готове ізольоване середовище для навчання роботі з Claude Code на Oracle.
Відкривається в **GitHub Codespaces** — на комп'ютері нічого встановлювати не треба.

Усередині контейнера вже є: Claude Code, SQLcl, Java 21, підключення до навчальної
бази через MCP. Дані виключно синтетичні (офіційні sample-схеми Oracle).

---

## Швидкий старт

1. Натисніть **Code → Codespaces → Create codespace on main**
2. Дочекайтесь збірки контейнера (перший раз ~3-5 хв)
3. У терміналі виконайте `claude`
4. Спробуйте: *«покажи список таблиць у схемі HR»*

Claude звернеться до бази через MCP-сервер SQLcl і відповість реальними даними.

---

## Що в базі

| Схема | Вміст | Доступ |
|---|---|---|
| **HR** | Працівники, відділи — 7 таблиць, 107 працівників | читання |
| **CO** | Клієнти, замовлення, JSON — 1 950 замовлень | читання |
| **SH** | Історія продажів — 918 843 рядки, партиціонування | читання |
| **Ваша схема** | Порожня, повний доступ | читання і запис |

Кожен учасник має власну схему. Об'єкти інших учасників для вас невидимі,
спільні sample-схеми захищені від запису.

---

## Налаштування секретів (один раз, для власника репозиторію)

Підключення до БД береться з Codespaces secrets. Без них Claude Code
працюватиме, але без доступу до бази.

**Settings → Secrets and variables → Codespaces → New repository secret**

| Секрет | Значення | Як отримати |
|---|---|---|
| `ADB_WALLET_B64` | wallet у base64 | `base64 -w0 wallet.zip` |
| `ADB_USER` | напр. `TRAINEE1` | видає тренер |
| `ADB_PASSWORD` | пароль користувача | видає тренер |
| `ADB_SERVICE` | напр. `acordtrain_low` | сервіс `_low` — обмежує паралелізм і дає більше одночасних сесій |

Wallet отримується з консолі OCI: **Autonomous Database → Database connection →
Download wallet**, або скриптом [`setup/03-download-wallet.sh`](setup/03-download-wallet.sh).

Після додавання секретів перестворіть Codespace, щоб `post-create.sh` їх підхопив.

---

## Структура

```
.devcontainer/
  Dockerfile          Java 21 + SQLcl
  devcontainer.json   Claude Code, Node, том для ~/.claude
  post-create.sh      Розпаковує wallet, зберігає з'єднання, перевіряє його
.mcp.json             MCP-сервер SQLcl — однаковий для всіх учасників
setup/                Скрипти розгортання БД (виконуються тренером один раз)
```

`.mcp.json` лежить у репозиторії навмисно: завдяки цьому всі учасники
отримують ідентичне підключення автоматично, без ручного налаштування.

---

## Безпека

- Жодних реальних чи конфіденційних даних — тільки офіційні sample-схеми Oracle
- Wallet і паролі передаються через Codespaces secrets, у git не потрапляють
- `.gitignore` окремо перекриває wallet-файли на випадок помилки
- Телеметрія Claude Code вимкнена (`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`)

Wallet — це облікові дані. Не пересилайте його у чатах і не комітьте.
